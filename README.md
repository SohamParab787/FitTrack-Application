# FitTrack – Fitness Tracking Application

FitTrack is an Android application designed to help users manage their fitness activities and support a healthier lifestyle through a simple and convenient mobile experience.

## 📱 Demo

Watch the application in action: [FitTrack Working Demo](FitTrackWorking.mp4)

## ✨ Features

- Simple and user-friendly Android interface.
- Convenient mobile-based fitness tracking.
- Supports users in monitoring their fitness journey.

## 🚀 Getting Started

### Prerequisites

- Android Studio
- Android SDK
- Compatible JDK version

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/SohamParab787/FitTrack-Application.git
   ```

2. Open the project in Android Studio.
3. Allow Gradle to sync the project dependencies.
4. Run the application on an Android emulator or a connected Android device.
